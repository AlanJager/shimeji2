# Base — character lock

Create a character reference for a desktop mascot named {name}.
Identity: {identity}. Style: {style_contract}.

Show the SAME character twice side by side: left = front view, right = side
view facing LEFT. Full body, neutral standing pose, arms relaxed, feet flat.
Compact, chunky silhouette that stays readable at 128×128 px; large head,
simple face, bold clean outline, flat or lightly shaded colors, max ~12 main
colors. {background_clause}

No text, scenery, ground shadow, glow, or props that are not part of the character.

`{background_clause}` is one of:

- native alpha: "transparent background"
- keyed: "perfectly flat pure {key_name} {key_hex} background; keep {key_hex} and similar colors out of the character"

The default key is solid flat pure green (#00FF00). No ground, no shadow, no border.
