# shimeji2 application icon

`shimeji2.png` is the master artwork for the application icon, created with
AI assistance for this project. It depicts an original generic desktop spirit;
it is not a portrait of an imported character. The project's zlib notice applies
to this project asset. The bundled shime character retains its separate upstream
notices under `assets/packs/shime/`.

`scripts/build-icon.sh` creates the standard 16–1024px ICNS representations using
macOS `sips` and `iconutil`; no image-generation service is needed to build.
