# shimeji2 公开测试版：先读我

支持 M 系列 Mac，最低 macOS 14。此包仍处于 beta，使用 ad-hoc 签名，尚未公证。

## 安装与首次打开

1. 打开 DMG，把 shimeji2.app 拖到 Applications；ZIP 用户解压后移动应用即可。
2. 尝试打开应用。若系统提示开发者无法验证，且你已核对下载来源和 SHA256，
   打开系统设置 → 隐私与安全 → 仍要打开，再确认打开。
3. 桌宠出现后可左键拖动、松开抛出，右键打开菜单。菜单栏 Quit 退出。

以上系统操作依据 [Apple 首次打开说明](https://support.apple.com/en-us/102445)。
不要关闭整个系统的 Gatekeeper，也不需要安装 Java。

## 角色与设置

默认带白色 shime。Settings → 宠物可以拖入或选择角色 ZIP。
婉儿、花阳等自定义角色不包含在通用包内。
Control + Shift + S 切换隐藏/显示；设置可修改快捷键、大小和不透明度。
繁殖开启时会出现多个角色，可关闭繁殖或调整数量上限。
设置保存在 ~/Library/Application Support/shimeji2。

窗口恶作剧、声音和 Agent 反应默认关闭。只玩桌宠无需安装 Agent hooks。
若主动开启窗口恶作剧，需要在系统设置 → 隐私与安全 → 辅助功能授权此应用；
部分应用的窗口不允许搬动。ToDesk / 钉钉搬运和部分第三方包仍属于实验功能。

应用正常启动持续运行，不会在20秒后自动退出。
它的图标由 AI 辅助生成；默认 shime 素材保留上游许可与署名。

## 反馈与卸载

反馈时附上应用版本、Mac 芯片、macOS 版本、角色包来源、复现步骤，
以及问题发生于桌面还是某个应用窗口。截图/录屏可帮助确认动作与边界问题。
从可信渠道提供素材，避免附上个人配置或私密窗口内容。

卸载：先从菜单栏 Quit，再删除应用。保留设置可便于下次安装；
需要彻底清理时自行删除上述 Application Support 目录。
