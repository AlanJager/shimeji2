# Mac 番茄钟桌面验收

使用本次构建的 `.app` 和临时 `--profile /tmp/shimeji2-focus-review`；不要修改个人配置。下列项目需要真实 WindowServer 或人工操作，未执行项保持未勾选。

- [ ] 菜单栏“开始专注”启动 25:00；原生设置“专注”页可进入并暂停/继续/结束，状态与菜单一致。
- [ ] 三个时长 25/5/15 可编辑，Return 自动保存；重开 App 保留偏好但不恢复上一轮计时。非法/空输入回退到 1–180 分钟范围。
- [ ] 临时 profile 配置目录设为只读后修改专注偏好：控件恢复原值，独立错误文字持续可见且不被每秒倒计时覆盖，当前计时不变；恢复目录写权限并成功修改后错误消失，重开 App 保留新值。
- [ ] 真实 25 分钟连续运行；结束只计一轮，菜单/设置保留完成状态，等用户开始休息。第四轮后显示长休息，取消不计入完成。
- [ ] 专注时主角色和不同包的额外角色安静停在屏幕工作区底边；默认 shime 为安静姿态；无适用姿态包仍可见。
- [ ] 进入专注前拖动/爬墙/抛出/窗口搬运，进入后不滞留半空；正在搬运窗口走现有恢复路径。
- [ ] 专注中拖动角色仍跟手，松手就地停放；右键、隐藏、移除、新增角色可用。新角色直接安静出现。
- [ ] 专注时将角色数量上限设为 1，分别通过菜单移除、全部移除、角色禁用和右键 Dismiss 后重新新增；主角色与额外角色都可立即新增，不残留旧数量占用。
- [ ] 原先 Pause/Hide/Reduce Motion 在结束专注后保持；专注期间修改声音/繁殖/恶作剧等偏好不被旧设置覆盖。
- [ ] 隐藏或移除所有桌宠、暂停动画时倒计时继续；没有角色也可从设置控制计时。
- [ ] 锁屏、切换登录会话和系统休眠暂停番茄钟；解锁/唤醒不会自动继续；重叠原因清除前“继续”不可用。
- [ ] 仅显示器关闭、切换 Space、应用窗口遮挡不暂停番茄钟。
- [ ] 菜单保持打开时倒计时持续更新，截止仍能完成；点击菜单和重复唤醒不重复计轮或提示。
- [ ] 首次启动番茄钟或开启“系统提醒”时出现原生通知授权；允许、拒绝两条路径均能计时。
- [ ] 到点原生通知在工作应用和打开 Settings 时均验证；系统专注模式可抑制横幅，但菜单/设置仍有完成状态。
- [ ] 默认提示音关闭；打开后每阶段只响一次，独立于角色包声音。退出后无残留定时通知。
- [ ] “头顶耐心条与倒计时”默认关闭；开启后显示“耐心：MM:SS”和缩短的条，不抢键盘焦点、整张卡片不吃鼠标，随拖动/休息动画更新，Hide/锁屏时隐藏。
- [ ] 设专注 1 分钟，观察剩余 45/30/15 秒时依次切黄/橙/红；暂停时条与时间保持不变，继续不回满。完成保留“00:00 · 已完成”和空条，结束本轮隐藏，新阶段满格；运行中修改时长不改变当前比例。
- [ ] 开启耐心卡片并完成一轮，全部移除桌宠后重新新增；普通动画时钟运行时，新桌宠立即重新显示“00:00 · 已完成”和空条，无需启动下一阶段。
- [ ] 没有桌宠时启动并完成一轮，再新增桌宠；普通动画时钟运行时立即显示当前红色“00:00 · 已完成”和空条。
- [ ] 专注刚开始、耐心条仍为绿色时全部移除桌宠，等本轮完成后重新新增；立即显示当前红色“00:00 · 已完成”和空条，不残留移除前的绿色进度。
- [ ] 在主屏上沿、左右边缘、负坐标副屏拖动桌宠，耐心卡片保持可见，顶端不足时放到角色下方；切换 Space 时不抢焦点。
- [ ] Agent 事件在专注期间仍被接收，但不触发姿态插入、自动新角色或声音；倒计时标签不与 Agent 标签重叠。
- [ ] 多显示器、不同缩放与全屏 Space 验证标签和静态角色位置。
- [ ] 运行专注及暂停专注时拔掉角色所在的外接显示器：主角色、额外角色和标签立即回到剩余屏幕可见区，角色仍静止，未启动周期动画/窗口轮询。
- [ ] 分别测番茄钟关闭、运行且静态陪伴、暂停计时三组 CPU/唤醒；运行倒计时独立于 40 ms 动画时钟，暂停/Idle 无重复番茄钟 timer。

实现后应同时运行 headless timer/runtime 测试、Mac Power 测试与 workspace fmt/clippy/test；这些不代替上述实机项目。
