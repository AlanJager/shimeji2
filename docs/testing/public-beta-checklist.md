# Public beta acceptance

Record the app/archive hash, macOS version, chip, selected pack and observed result.
Use throwaway profiles and one application process at a time for local checks.
Do not mark another machine's acceptance from local-only evidence.

- [ ] Download/extract on a second Apple Silicon Mac; follow the documented first-open flow.
- [ ] Move the extracted app to a different folder and verify it loads its own 46-image pack.
- [ ] Launch without --seconds; remain running past20seconds and exit from menu-bar Quit.
- [ ] Confirm the application icon in Finder and the Settings window opens.
- [ ] Drag by opaque art, release upward/downward/left/right; right-click opens the menu.
- [ ] Transparent padding allows clicks to reach an underlying test window.
- [ ] Hide/show through the menu and Control+Shift+S; change the shortcut in Settings.
- [ ] Change size/opacity, relaunch and verify persistence in the throwaway profile.
- [ ] Import a trusted role ZIP through drag/drop and the file picker; enable/disable it.
- [ ] Ordinary maximized windows do not trigger ceiling poses at the desktop floor.
- [ ] Retained throws at all four edges remain visible and do not teleport through the desktop.
- [ ] Test sleep/wake, secondary displays and display-layout changes; record limitations.
- [ ] Mischief stays off until explicitly enabled; verify a real movable TextEdit window separately.
- [ ] Agent hooks stay absent until explicitly installed; record the supported agent/session scenario.

The initial candidate has no second-machine, broad multi-display or long-duration
acceptance claim. Test reports must distinguish performed checks from open items.
