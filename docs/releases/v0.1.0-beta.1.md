# shimeji2 v0.1.0-beta.1

桌面上的小角色，这次不用 Java。

shimeji2 是 shimeji4mac 的 Rust 重写：原生菜单栏应用，跑经典 Shimeji 角色包。一只白色 shime 会沿着屏幕和窗口边缘走、爬、挂、坐，你也可以把它拎起来扔出去。点在它周围的空白处，点击会落到下面的应用。

**Public beta for Apple Silicon Macs on macOS 14 or later.** The app reports version 0.1.0. Built and run so far on macOS 15 only. Not notarized. Settings are in Chinese; menus are in English.

## 下载

| 文件 | 给谁 |
|---|---|
| `shimeji2-0.1.0-beta.1-macos-arm64.dmg` | 拖进「应用程序」 |
| `shimeji2-0.1.0-beta.1-macos-arm64.zip` | 解压后移动应用 |
| `SHA256SUMS.txt` | 下载后核对 |
| `shimeji2-0.1.0-beta.1-source.zip` | 想自己构建的人 |

```sh
shasum -a 256 -c SHA256SUMS.txt
```

第一次打开会被系统拦住。到 **系统设置 → 隐私与安全性**，点 **仍要打开**，再确认打开。不要关闭 Gatekeeper。包里的 `READ-ME-FIRST.md` 写了同样的步骤。

这个包是 ad-hoc 签名，没有 Developer ID，也没有公证。Intel Mac 不在这次测试范围内。

## 打开之后

- 菜单栏里的 **し**：暂停、隐藏、再叫一只出来、打开设置、退出。
- 左键按住拖动，松手时按鼠标速度抛出。右键打开这只角色的菜单。
- **Control + Shift + S** 隐藏或显示全部。
- **设置 → 宠物** 可以拖入角色 ZIP 或文件夹。支持经典日文 XML、Shimeji-ee 英文 XML，以及 Codex 精灵表。
- 默认会繁殖，上限 50。不想要一桌，到 **设置 → 外观与动作** 关掉自动繁殖。
- 自带的白色 shime 与上游 46 张图、两份行为文件逐字节一致。其他角色不附在包里，导入前请看原作者的许可。

## 这个版本先别做

**不要安装智能体钩子。** 设置 → 智能体里的安装器会把钩子指到应用自己的可执行文件，而不是附带的 `shimeji-hook`。应用会因此退出，Claude Code 可能把这次失败当成每次对话的阻塞错误。已经装过的，用同一页的 **卸载…** 去掉。

Finder 的「压缩」会在 ZIP 外面再套一层文件夹，这种包导入会提示找不到动作文件。解压后，把里面那一层文件夹拖进去。

## 已经包含的修正

- 角色包文件名是 Unicode NFD（macOS 上很常见）时，图片能对上对应姿势，不再变成空白。
- 除 macOS 壳以外的代码，可以在 Linux 上通过格式、clippy 和测试。

## 还不稳定的部分

窗口恶作剧和动作声音默认关闭。恶作剧需要辅助功能权限；因为是 ad-hoc 签名，每次换包都要重新授权。系统设置、终端、钥匙串的内置保护按英文应用名匹配，中文系统请自己加屏蔽规则，或者先别开。ToDesk / 钉钉这类窗口还没有做过真实搬运验收。

还有这些已知问题，细节在 [README](https://github.com/AlanJager/shimeji2#known-issues-and-limitations)：

- 一个角色包里有多套同名图片时，可能画错图或点错区域。
- 多台显示器之间切换焦点时，角色可能跳一下或掉下去。
- 缩放不是 100% 时，脚会略高于或低于地面。
- 动作声音会循环，混用单声道和立体声 WAV，或切换音频设备时可能崩溃。请保持声音关闭。
- 十七个 Shimeji-ee 扩展动作会变成原地停留。

另一台 Mac 上的第一次打开、休眠唤醒和长时间挂机还没有验收。

反馈请开 [issue](https://github.com/AlanJager/shimeji2/issues)，写上芯片、macOS 版本、角色包从哪来、怎么复现，以及发生在桌面上还是某个窗口上。截图有用。不要附个人配置或私人窗口内容。
