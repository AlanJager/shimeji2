# shimeji2 v0.1.0-beta.1

首次公开测试候选版本：Rust 编写的原生 macOS Shimeji 桌宠运行器，无需 Java。
支持 Apple Silicon / macOS14+；当前实测 macOS15。

## 可以体验

- 左键拖动、按鼠标速度抛出、桌面和窗口边界活动。
- 中文原生设置、菜单栏控制、隐藏快捷键、角色 ZIP 导入。
- 默认白色 shime，完整保留上游素材与许可说明。
- 正常启动持续运行；显式 --seconds 和性能测试仍可定时结束。
- 独立应用图标、首次打开说明和 SHA256 校验文件。

## 安装

解压 ZIP 或打开 DMG，把 shimeji2.app 移动到 Applications 后打开。
当前是 ad-hoc 签名测试包，尚未 Developer ID 签名和公证；
首次打开操作见随包 READ-ME-FIRST.md。

## 已知边界

窗口恶作剧和 Agent hooks 属于实验功能，默认关闭。
ToDesk / 钉钉的真实搬运验收、部分第三方包扩展、第二台机器首次安装、
广泛多屏/休眠和长时间测试仍待补充。自定义婉儿/花阳素材不随通用包分发。
程序许可与角色素材说明分别保留，应用图标为 AI 辅助生成。
